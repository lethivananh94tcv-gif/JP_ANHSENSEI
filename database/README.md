# Database Guidelines & Flyway Baseline — ANH SENSEI

## 1. Cơ sở dữ liệu hiện tại
Tệp `ANH_SENSEI_database.sql` chứa toàn bộ cấu trúc 38 bảng thuộc schema `public` của dự án ANH SENSEI (phiên bản SRS 2.0).

## 2. Quy trình Baseline và Migration với Flyway
1. Tệp SQL này đã được tích hợp làm **baseline migration** tại đường dẫn:
   `backend/src/main/resources/db/migration/V1__baseline.sql`

2. Khi backend Spring Boot khởi chạy lần đầu tiên:
   - Flyway sẽ tự động chạy `V1__baseline.sql` để tạo toàn bộ 38 bảng và các index/constraint liên quan.
   - Trạng thái `ddl-auto` của Hibernate được đặt là `validate` để đảm bảo JPA entities khớp chính xác với database schema.

3. **Khi cần thay đổi database schema về sau**:
   - Tuyệt đối **không chỉnh sửa** file `V1__baseline.sql` hoặc các migration đã chạy.
   - Tạo file migration mới theo quy chuẩn đặt tên Flyway:
     - `V2__add_new_column_to_users.sql`
     - `V3__create_new_feature_table.sql`
   - Đặt file migration mới tại `backend/src/main/resources/db/migration/`.

## 3. Quy tắc phát triển
- Tên bảng và tên cột dùng chuẩn `snake_case`.
- Khóa chính dùng `BIGINT GENERATED BY DEFAULT AS IDENTITY`.
- Lưu timestamp theo `TIMESTAMPTZ` chuẩn UTC.
- Tuyệt đối không dùng `spring.jpa.hibernate.ddl-auto=create` hoặc `create-drop`.
